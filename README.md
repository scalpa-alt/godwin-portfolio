# Godwin Paschal Mwenda | Portfolio

Personal portfolio website of Godwin Paschal Mwenda, a Computer Science student at Zetech University with training in Data Science & Analytics and Cyber Security. It showcases my web development, data and creative media work.

**Live site:** https://paschalportfolio.vercel.app

## What's on the site

- **About:** who I am, what I do, and my education and certifications
- **Projects:** case studies with screenshots, tech used and live links
  - **OuterCircle:** an anonymous mental health support platform I develop and manage
  - **DukaFlow (ShopFlow POS):** a barcode-scanning point-of-sale app for small shops
- **Skills:** development and systems, data and analytics, creative media
- **Contact:** email, WhatsApp and phone, plus a downloadable CV

## Built with

- Semantic HTML, CSS and a small amount of JavaScript, all in a single `index.html`
- No frameworks or build step
- Responsive layout that works on phones, tablets and desktops
- Automatic light and dark mode based on the visitor's device settings

## Run it locally

No installation needed. Download or clone the repository and open `index.html` in a browser.

```sh
git clone <this-repository-url>
cd <repository-name>
```

## Publish it

**GitHub Pages**
1. Push the files to a public repository.
2. Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, and save.
3. Your site goes live at the link shown there within a couple of minutes.

The site is plain static files, so it also works on any static host such as Netlify or Vercel.

## Updating content

- **Text and links:** edit `index.html`.
- **Screenshots:** replace the files in `images/`, keeping the same file names.
- **CV:** replace `Godwin-Paschal-Mwenda-CV.pdf`, keeping the same file name so the Download CV button keeps working.
